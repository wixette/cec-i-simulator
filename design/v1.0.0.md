# v1.0.0: the review, and frozen

**Status:** released 2026-11-22, the first release that is not a pre-release ([the release](https://github.com/wixette/cec-i-simulator/releases/tag/v1.0.0)).

No new features. The release makes what is there sound, documented and easy to show, and fixes what it promises from now on.

Related documents: the plan ([roadmap.md](roadmap.md)), the review's findings ([v1.0.0-review.md](v1.0.0-review.md)).

## The tasks, in order

1. **Code and docs review:** code quality, test coverage, and the docs agreeing with each other and with the code. The findings go in [v1.0.0-review.md](v1.0.0-review.md), for the owner to choose what is fixed.
2. **Fix what the review finds,** as the owner chooses.
3. **A full README:**
   - first for newcomers and learners: attractive, with a smooth learning curve, not a manual;
   - then for developers.
   
   In Chinese (written in Chinese) and in English.
4. **Shot and video tools,** as the TRS-80 simulator has them:
   - the README's screenshots;
   - stills and short clips for social media posts.
   
   The moments are chosen to show the simulator at its best.
5. **Frozen link format and other protocols:**
   - **The link format:** `#view=3d|2d`, `?lang=` and the developer options `?debug` and `?selftest`. Document it, decide whether `?debug` stays, and test that old links keep working (`tests/link.test.js`).
   - **The file formats the page writes:** `.bas`, `.logo`, and the disk images it saves.
6. **Final check,** the owner checking by hand too.

Added at the owner's agreement:

7. **Accessibility:**
   - every menu, dialog and tab usable from the keyboard alone;
   - every control named for a screen reader, the icon-only phone layout included;
   - contrast in the dark theme.
8. **Browsers and devices:** Safari (macOS, iPhone, iPad) and Firefox, beside Chrome: WebGL, the audio unlock, files dropped and opened.
9. **Load size and speed:** what a first visit fetches (the model, the ROMs, the fonts), on a slow network; a size budget, checked by a test.
10. **The full 6502 suite** (`pnpm test:6502`) once more, last run for v0.0.2.
11. **The GitHub page:**
    - a 1280 × 640 social preview image, made by the shot tools (task 4);
    - the description and topics brought up to date.
12. **Native readers of the translations,** 繁體中文, 日本語 and 한국어 above all, if the owner can find them.
13. **What 1.0 promises:** a short note on what stays stable from now on (the link format, the save formats, the disk images) and how later versions are numbered.

## What was done

- **1, 2. Review and fixes:** [v1.0.0-review.md](v1.0.0-review.md), with what was done for each finding.
- **3. README:** rewritten in Chinese (written in Chinese, not translated) and in English: what the machine was, the first minutes, a picture for each thing it does, the programs, the lessons, disks, the languages, how it compares with the real one; then developers. The pictures are in `screenshots/zh/` and `screenshots/en/`, each README's in its own language, made by `pnpm shots --readme`.
- **4. Shots and clips:** `pnpm shots` (20 shots, the social preview among them) and `pnpm video` (10 clips), in any of the ten languages ([../docs/development.md](../docs/development.md)). A clip's sound is rendered from the page's own speaker on the clip's frame clock, so the power-on beep, `MUSIC` and the games are heard in step with the picture.
- **5. Frozen:** the link format (`js/app/link.js`, `tests/link.test.js`: unknown fields ignored, the ten languages and their aliases pinned) and the file formats, in [../docs/stability.md](../docs/stability.md).
- **6. Final check:** the owner's, by hand: no blocking issues.
- **7. Accessibility:** an audit of each tab at desktop and phone sizes: no control without a name, no picture without alt; the text below WCAG AA contrast (the instruments' addresses, bytes, labels, menu notes, captions, `#8c8c8c` on the dark cards) brightened to `--md-on-surface-variant`, and a lit bit's label to the container's own; the 3D view named (`role="img"`). `tests/browser/access.mjs` runs the audit.
- **8. Browsers:** Firefox, headless over WebDriver BiDi: starts, BASIC answers, the Chinese system types, WebGL 2 draws, no errors. The owner checked by hand Safari on macOS, Firefox, and Safari on an iPhone: no problems found.
- **9. Load size:** the lessons' photographs served as 1,200-pixel web copies (64–180 KB, from up to several MB). `tests/size.test.js` keeps a budget: the model under 5.5 MB, the ROMs 340 KB, the page's code 600 KB, a first visit under 9 MB.
- **10. 6502:** `pnpm test:6502`, all 1,510,000 cases, none failed.
- **11. GitHub page:** the description and topics set; the social preview (`social-preview.jpg` from `pnpm shots`) for the owner to upload in the repository's settings.
- **12. Native readers:** none for 1.0.0, at the owner's word; the translations stand as written, and a native reader's corrections are welcome in any later 1.x (a PATCH).
- **13. What 1.0 promises:** [../docs/stability.md](../docs/stability.md).
