# v0.0.1: the machine, on desktop and phone

**Status:** built on branch `dev-v0.0.1`, waiting for the owner's check.

v0.0.1 is the first pre-release. Its aim: **every feature of the machine works**, in a page laid out after the TRS-80 simulator's, on a desktop and on a phone, in 简体中文 and English.

Related documents: the page's principles and decisions ([../docs/ui-design.md](../docs/ui-design.md)), the machine's decisions ([decisions.md](decisions.md)), the conventions ([../docs/conventions.md](../docs/conventions.md)), what the machine is and what was measured on it ([../research/README.md](../research/README.md)).

## 1. What a visitor can do

- **See the CEC-I and its TV in 3D** (the default): Front, Three-quarter, Keyboard, Screen, Back, Inside (the lid and keyboard as glass), Taken apart (the lid, the keyboard turned over on its cable, the main board, with the computer off). Every part named on hover, in the page's language.
- **Switch to 2D**: the TV large and sharp, its knobs and button; the keyboard a drawer under it, its keys drawn from the 3D model's.
- **Use the machine:** Western BASIC, the Chinese system (pinyin and 区位), LOGO, the monitor and mini-assembler, the self-test (Ctrl-Reset-TEST), the speaker (`MUSIC`, the beep). Every key from the visitor's keyboard (D7), or clicked.
- **Type in, open and save:** text pasted or written is typed on the machine's keys, Chinese through 区位 (D8); a BASIC file opened is typed in after `NEW`; the program in memory is saved as UTF-8 text.
- **Choose the display** (a colour TV, a black-and-white TV, a green monitor, D6) and the case's finish (as new, as found).
- **Read** the Start tab (the machine, a first few minutes, the keys, Chinese), References, About.

## 2. What was carried over, and how

The machine core, the 3D model and the 2D view's parts went in with review, each piece:

1. **Read** it whole.
2. **Review** every rule in it against its source (the books, the real machine, MAME).
3. **Improve** names, types, comments and structure to this repository's conventions; reword every comment for a public reader; remove what this release does not use.
4. **Verify**, with tests from the sources.

| Part | Carried over | Changed in review |
|---|---|---|
| The 6502 (`js/sim/cpu6502.js`) | as it was: passes all SingleStepTests | comments; the suite's runner pinned to a commit, with retries |
| The machine (`machine.js`) | the memory map, the soft switches, the latch, the frame | power-on clears the keyboard's latch and the speaker; the debugging hooks for v0.0.2's instruments taken out until then; `screenText()` |
| The picture (`video.js`) | text, lo-res, hi-res, the colours, the green text rule | the three displays (D6) |
| The keyboard (`keyboard.js`, `key-holds.js`, `host-keys.js`) | codes from U26, repeat, Ctrl-Reset, pointer-held modifiers | the key for each code (the typist's keys shown down); a typist that waits and types braces; every key reachable with Alt too (D7); a stand-in code table dropped (U26 is read) |
| The speaker (`sound.js`) | as it was | silent while the machine runs faster |
| The 3D model (`model/`) | the params, the Blender scripts, the generators, the stickers and fonts | sources reworded, values unchanged (checked); the Chinese labels of every part; rebuilt |
| The 3D parts (`js/scene/`) | the TV's screen, the knobs, ghosting, the ribbon cable, the keyboard's motion | bound to the System in one module (`machine3d.js`), as the TRS-80's `desk3d.js`; viewer and framing are the TRS-80's |
| The 2D view (`js/flat/`) | the TV and the keyboard drawn flat, the key and rocker art from the model | the keyboard as a drawer (U10); labels translated |

New here: the page (`js/app/`, `js/ui/`, `css/`, after the TRS-80 simulator's), the System (`system.js`: the rules every view shares), Chinese text (`chinese.js`), BASIC listings (`basic.js`), the ROM loader, the messages in two languages, the docs. Not carried over: any earlier page layout (the page is the TRS-80 simulator's), working notes (summarised in research/README.md), and any photograph but the six cleared ones.

## 3. Checks

- `pnpm check`: the reference check, the strict type check, and 130+ unit tests: the machine on its ROMs against the real one (`tests/machine.test.js`), the 6502's sample, the keyboard, the visitor's keys, Chinese text, BASIC listings, the picture, the speaker, the System's rules, the languages, the model's contract, the photographs' metadata, vendor/ and the stamps.
- `pnpm test:6502`: all 1,510,000 SingleStepTests cases.
- `pnpm test:browser`: the page in a headless Chrome (boot, keys, typein, views, flat, layout, dialogs, lang).
- `reuse lint`.

## 4. Known, for later releases

- Speed on slower devices: the machine runs slow rather than freeze when a frame's work runs over its budget; to be measured on a Chromebook and phones.
- The instruments, the programs, the lessons, the cassette and ten languages: v0.0.2 to v0.0.6.
