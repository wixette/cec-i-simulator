# v0.0.3: programs of our own

**Status:** released 2026-11-22 as a pre-release.

v0.0.3 gives the visitor programs worth running, written for the machine as programs of 1987 were: BASIC, with machine code where speed matters, and LOGO. 

Related documents: the page's principles and decisions ([../docs/ui-design.md](../docs/ui-design.md)), the machine's decisions ([decisions.md](decisions.md)).

## 1. The programs (P1)

Sixteen programs in six sections of the Programs menu. Programs of the time in their genres, with our own names, rules and pictures, never a copy of a particular program.

- **The language on the machine's screen.** Only the Chinese programs show Chinese, and run in the Chinese system. The others are in English, in Western mode, as the Apple II programs the machine also ran. Their titles and descriptions in the menu are translated with the page.
- **The mode chosen for the visitor.** Choosing a program switches the machine to the mode it runs in (Western BASIC, the Chinese system, LOGO) before typing it in.
- **Machine code where speed matters,** POKEd from `DATA` lines and called with `CALL`, as the type-in programs of the time did; BASIC for the rest, so that it can be read.
- **No saving yet:** the cassette recorder comes in v0.0.5.

## 2. What the machine taught us

- **Getting there from anywhere** (D14): Ctrl-Reset reaches BASIC's prompt from a running program and from the Chinese system; from LOGO it reaches the monitor, from which BASIC must start afresh (warm, it crashes: LOGO has used BASIC's zero page).
- **The Chinese system's screen** is hi-res page 2, about 17 characters by 9 lines over its input line; `HTAB` and `VTAB` do not place text there as in text mode, and a program's `GET` gets the raw keys (F3, the digits, F1), not characters: the input methods work only in the system's own line input.
- **`VAL` of a string read by `GET`** reads past it (`VAL` of "2" gave 2.2E+17); `ASC(A$)-48` is used instead, as programs of the time often did.
- **The font through the window**: reads from $4000-$BFFF go to the aux side while RAMRD is on, the CPU's own instruction fetches with them, so code that reads the font must run below $4000 (Big character's at $300; the word processor copies its fetch there).
- **Glyph numbers**: the font holds 256 half-width characters, then GB 2312's rows 1-9 (from 256) and 16-87 (from 1102), 94 a row.

## 3. Checks

- Unit tests (`tests/programs.test.js`): every listing typable, only the Chinese ones with Chinese; every machine code assembled and its DATA its bytes; each program typed in from a machine doing something else and run: Guess my number found by halving; the bar chart's heights and colours; the curves drawn; 中's 32 bytes fetched as the font holds them; both halves of BASIC against machine code the same; Snake steered to a coin; Bricks scoring; Mine hunt's mines, counts as shown on the text screen, flag and loss; the calendar's first days and lengths against JavaScript's own calendar; the clock 60 seconds in 60; the tunes' first notes' pitches; the kaleidoscope's procedures and colour; the idiom quiz played to full marks; the text editor's text in memory after typing, editing, wrapping and scrolling; Reading numbers against a JavaScript reading of the same numbers, and its refusals. The assembler (`tests/asm6502.test.js`): every documented opcode in every mode.
- Browser checks: Programs ▸ a program ▸ Type it in, from a running program, to its prompt.

## 4. The joystick, taken out

A joystick on the visitor's keys (a spring stick on paddles 0 and 1, Space and Ctrl its buttons, a pad on a phone) was built, then taken out at the owner's review: our programs are played on the keyboard, and through the joystick the arrows answered slower (the stick's swing, the games' thresholds); it is only for the era's own games, which the visitor cannot load before v0.0.5. It is planned for after v1.0.0 (roadmap). The machine's game port stays, reading as nothing plugged in.
