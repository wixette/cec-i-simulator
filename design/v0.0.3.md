# v0.0.3: programs of our own, and the joystick

**Status:** built on branch `dev-v0.0.3`, waiting for the owner's check.

v0.0.3 gives the visitor programs worth running, written for the machine as programs of 1987 were: BASIC, with machine code where speed matters, and LOGO. And it plugs in a joystick, played on the visitor's keys.

Related documents: the page's principles and decisions ([../docs/ui-design.md](../docs/ui-design.md)), the machine's decisions ([decisions.md](decisions.md)).

## 1. The programs (P1)

Fifteen programs in six sections of the Programs menu. Programs of the time in their genres, with our own names, rules and pictures, never a copy of a particular program.

- **The language on the machine's screen.** Only the Chinese programs show Chinese, and run in the Chinese system. The others are in English, in Western mode, as the Apple II programs the machine also ran. Their titles and descriptions in the menu are translated with the page.
- **The mode chosen for the visitor.** Choosing a program switches the machine to the mode it runs in (Western BASIC, the Chinese system, LOGO) before typing it in.
- **Machine code where speed matters,** POKEd from `DATA` lines and called with `CALL`, as the type-in programs of the time did; BASIC for the rest, so that it can be read.
- **No saving yet:** the cassette recorder comes in v0.0.5.

## 2. The joystick (P2)

The machine's game port, with a spring joystick of the time in it, played on the visitor's keys.

- **Plugged in from the helper strip:** a Joystick button after TV, lit while plugged in. Unplugged (as at first), the port reads as with nothing in it: the paddles 255, the buttons up. Plugged in, the stick rests at the centre, 128 on both axes.
- **A spring stick:** an arrow held pushes the stick to that edge in 0.2 s; let go, it springs back to the centre. Paddle 0 is left and right, paddle 1 up and down (`PDL(0)`, `PDL(1)`).
- **The keys while it is plugged in:**

| The joystick | The visitor's key | The machine sees the key too |
|---|---|---|
| The stick | the arrows | no: they move the stick only |
| Button 0, the main action (fire, open, start) | Space | yes: a space is still typed |
| Button 1, the second action (flag, bomb) | Ctrl, left or right | yes: Ctrl still works |

- **On a touch screen,** a row under the picture holds four arrows on the left and the buttons A (0) and B (1) on the right, while the joystick is plugged in; the machine's keys stay free to tap.

## 3. What the machine taught us

- **Getting there from anywhere** (D14): Ctrl-Reset reaches BASIC's prompt from a running program and from the Chinese system; from LOGO it reaches the monitor, from which BASIC must start afresh (warm, it crashes: LOGO has used BASIC's zero page).
- **The Chinese system's screen** is hi-res page 2, about 17 characters by 9 lines over its input line; `HTAB` and `VTAB` do not place text there as in text mode, and a program's `GET` gets the raw keys (F3, the digits, F1), not characters: the input methods work only in the system's own line input.
- **`VAL` of a string read by `GET`** reads past it (`VAL` of "2" gave 2.2E+17); `ASC(A$)-48` is used instead, as programs of the time often did.
- **The font through the window**: reads from $4000-$BFFF go to the aux side while RAMRD is on, the CPU's own instruction fetches with them, so code that reads the font must run below $4000 (Big character's at $300; the word processor copies its fetch there).
- **Glyph numbers**: the font holds 256 half-width characters, then GB 2312's rows 1-9 (from 256) and 16-87 (from 1102), 94 a row.

- Unit tests (`tests/programs.test.js`): every listing typable, only the Chinese ones with Chinese; every machine code assembled and its DATA its bytes; each program typed in from a machine doing something else and run: Guess my number found by halving; the bar chart's heights and colours; the curves drawn; 中's 32 bytes fetched as the font holds them; both halves of BASIC against machine code the same; Snake steered to a coin; Bricks scoring; Mine hunt's mines, counts, flag and loss; the calendar's first days and lengths against JavaScript's own calendar; the clock 60 seconds in 60; the tunes' first notes' pitches; the kaleidoscope's procedures and colour; the idiom quiz played to full marks; the word processor's text in memory after typing, editing, wrapping and scrolling. The assembler (`tests/asm6502.test.js`): every documented opcode in every mode; the joystick (`tests/joystick.test.js`), as BASIC reads it.
- Browser checks: the joystick from the strip, its keys and the phone's pad; Programs ▸ a program ▸ Type it in, from a running program, to its prompt.
