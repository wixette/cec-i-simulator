# Privacy and what the page keeps

The simulator runs entirely in your browser. It has no server of its own beyond the files it is served from, no account, no analytics and no cookies.

**What it sends:** nothing. Text you type in or paste, and a BASIC file you open, are read in the page and never uploaded. A program you save is made in the page and handed to your browser as a download.

**What it keeps,** in your browser's local storage for this site, so that the page opens as you left it:

| Key | What |
|---|---|
| `ceci.lang` | the language you chose |
| `ceci.power` | whether the computer and the TV were on |
| `ceci.view` | 2D or 3D |
| `ceci.dock` | the dock's tab, height and whether it was folded |
| `ceci.sound` | sound on or off |
| `ceci.strip` | the helper strip folded or not |
| `ceci.drawer` | the 2D view's keyboard drawer open or closed |
| `ceci.display` | the set the computer is plugged into (colour TV, black-and-white TV, green monitor) |
| `ceci.finish` | the case as new (the default) or as found |

Nothing else: the machine's memory is not kept, and is gone when the page closes (design/decisions.md, D10). Clearing this site's data in your browser forgets all of it. In a private window, or with site data blocked, nothing is kept and the page works the same.
